# Superhuman-inspired Design Spec

This design spec is built for the AI Web Design Portfolio landing page.

## Typography
- Primary font: `Inter`
- Secondary font: `Plus Jakarta Sans`
- Headings: strong, high contrast, large scale
- Body text: comfortable line-height and readable sizes

## Colors
- Background: soft, light gradient with subtle blue/purple accents
- Accent: deep blue/purple (`#4338ca`)
- Body text: dark gray/black for strong readability
- Cards: white with soft border and shadow

## Spacing
- Generous vertical rhythm across sections
- Clear gaps between cards and content blocks
- Responsive padding at smaller breakpoints

## Layout
- Top navigation with brand and anchor links
- Hero section with bold headline, supporting text, and clear CTA
- Feature and pricing cards displayed in a harmonious grid
- Work section with split content and statistics
- Contact section with a focused action panel

## Goal
Implement the AI Web Design Portfolio using the Superhuman design language:
- polished modern surfaces
- strong typographic hierarchy
- clear content structure
- responsive layout
