# AI Web Design Landing Page

A static landing page based on the provided visual design.

## Files
- `index.html` — page markup
- `styles.css` — layout and styling

## Open locally
1. Open `index.html` in your browser.
2. Or run a local server from the `ai-web-design-landing` folder.

## Optional local server
If you have Python installed:

```powershell
cd C:\Users\dclou\ai-web-design-landing
python -m http.server 8000
```

Then open `http://localhost:8000`.
